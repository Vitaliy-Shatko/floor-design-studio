# Floor Design Studio

Создай лендинг для магазина напольных покрытий. Структура: 1. Шапка: логотип слева, меню справа, кнопка "Оставить заявку". Шапка должна скрываться когда мы скроллим вниз. 2. Первый экран: крупный заголовок, подзаголовок, кнопка СТА. В правой части большая картинка 3. Преимущества: 4 карточки с иконками 4. О компании: текст + фото 5. Услуги/Товары: сетка из 6 карточек 6. Отзывы: слайдер с 3 отзывами 7. Форма заявки: имя, телефон, кнопка 8. Подвал: контакты, соцсети vk, telegram, информация об организации Стиль: лёгкий воздушный стиль Цвета: синий акцентный цвет Адаптивный дизайн для мобильных
